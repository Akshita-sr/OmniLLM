ACTIVE AND RECENT PROJECTS
--------------------------

Project A — OmniLLM / Embodied LLM Arena (current host project of this Pepper)
  Scope: Multi-LLM smart routing for a social robot. The Pepper robot in this
    room is used as the embodiment platform. We compare five experimental
    conditions: a fixed cloud LLM (Condition A — GPT-4o-mini), a fixed local
    LLM (Condition B — Llama 3 via Ollama), smart routing (Condition C — best
    LLM per task type), consensus / council (Condition D — three LLMs whose
    answers are synthesised), and a no-RAG control (Condition E).
  Hypotheses: (H1) embodied HRI rankings differ from text-only benchmarks;
    (H2) smart routing beats any single fixed model; (H3) RAG-augmented
    responses are more accurate and trustworthy.
  Status: experimental sessions are running with Pepper, both with Choregraphe
    virtual robot (for development) and on the real robot at DIBRIS.

Project B — Cultural Competence in Social Robots (CARESSES heritage)
  Topic: building cultural awareness into social robots used for assistive
    interaction with older adults. Continues research originally carried out
    in the CARESSES EU/JST project, in which Pepper was deployed in care
    homes in the UK, Italy and Japan and adapted its behaviour to each
    resident's cultural background.
  Outputs: cultural knowledge bases, ontologies for caregiving, and HRI
    studies on perceived empathy and trust across cultures.

Project C — Long-Term Autonomy for Social Robots
  Topic: keeping a social robot useful over days and weeks rather than only
    in 10-minute demo sessions. Themes: drift-free localisation, automatic
    fault recovery, social adaptation to recurring users, log analytics for
    failure cases.

Project D — HRI Methodologies and Evaluation
  Topic: methodological work on how to evaluate HRI — Likert questionnaires,
    Godspeed subscales (Bartneck et al. 2009), pairwise preferences, ELO-style
    leaderboards, and observer ratings. The OmniLLM study reuses this
    machinery to benchmark LLMs embodied in Pepper.

Project E — Assistive and Domestic Autonomous Systems
  Topic: assistive robotics in the home, including task planning, navigation
    and natural language interaction. Often collaborates with the
    bioengineering and rehabilitation groups inside DIBRIS.

THIS PEPPER UNIT
----------------
The Pepper in this lab is a NAOqi 2.5 unit. It is used for the OmniLLM
Embodied LLM Arena study, and is also available for short demonstrations and
teaching activities. It runs the OmniLLM Python stack (LangGraph, LiteLLM
gateway, ChromaDB RAG pipeline, Whisper STT) and bridges to NAOqi via a
Python 2.7 process. See the README of the OmniLLM repository for the full
two-process architecture.
