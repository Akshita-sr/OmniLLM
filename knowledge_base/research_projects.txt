IRAI LAB — ACTIVE RESEARCH PROJECTS
=====================================

PROJECT 1: OmniLLM — Multi-LLM Smart Routing for Embodied AI
--------------------------------------------------------------
Principal Investigator: Prof. Alejandro Martinez
Team: Alice Chen (PhD), Eva Rossi (Postdoc)
Status: Active — Phase 2 (Experiment running April–June 2026)
Funding: EU Horizon Grant #HE-2024-ICT-872
Description:
  OmniLLM is a living, extensible platform for comparing, routing, and
  orchestrating multiple Large Language Models simultaneously. The project
  investigates whether LLM rankings from text-only benchmarks (MMLU,
  Chatbot Arena) remain valid in embodied human-robot interaction settings.
  The Pepper robot is used as the evaluation platform, with participants
  interacting with 5 different LLM backends (GPT-4o-mini, Claude Haiku,
  Gemini Flash, DeepSeek-V3, Llama3:8b) under counterbalanced conditions.
Key publications:
  - "Dynamic LLM Routing for Social Robots" (Under review, IEEE RO-MAN 2026)
  - "OmniLLM: A Plugin Architecture for Multi-Model Evaluation" (Preprint)

PROJECT 2: Autonomous Navigation with Semantic Maps
----------------------------------------------------
Principal Investigator: Dr. Sarah Patel
Team: George Okonkwo (PhD), David Kim (Intern)
Status: Active — Phase 1 (Hardware integration)
Funding: UKRI Robotics Hub Grant
Description:
  Developing a semantic mapping system that combines LiDAR SLAM with LLM-based
  scene understanding. The TurtleBot4 learns to navigate using natural language
  instructions ("Go to the coffee machine") by grounding spatial language in
  occupancy grid maps.
Key publications:
  - "LLM-Grounded Navigation in Indoor Environments" (ICRA 2026, accepted)

PROJECT 3: Affective Human-Robot Interaction
---------------------------------------------
Principal Investigator: Prof. Alejandro Martinez
Team: Carol Dupont (Visiting Researcher), Fatima Al-Zahra (MSc)
Status: Active — Data collection phase
Funding: Internal seed grant
Description:
  Exploring how Pepper's expressive capabilities (LED patterns, gesture
  vocabulary, vocal prosody) affect user trust and perceived intelligence.
  Develops a computational model of social cue synchronisation for HRI.
Key publications:
  - "Timing Social Cues in Human-Robot Conversation" (HRI 2026, submitted)

PROJECT 4: Multimodal LLM Grounding
--------------------------------------
Principal Investigator: Prof. Alejandro Martinez
Team: Eva Rossi (Postdoc), Ivan Petrov (Visiting Prof.)
Status: Planning — starts Q2 2026
Funding: Bilateral Italy-UK research programme
Description:
  Connecting vision-language models (LLaVA, Gemini Vision) to robot cameras to
  enable scene-aware responses. "Pepper sees a book on the table and can answer
  questions about it."

PROJECT 5: Reinforcement Learning for Dexterous Manipulation
-------------------------------------------------------------
Principal Investigator: Dr. Sarah Patel
Team: George Okonkwo (PhD)
Status: Active — Simulation experiments
Funding: EPSRC DTP Studentship
Description:
  Using PPO and SAC to train manipulation policies for the lab's 7-DoF arm.
  Comparing sim-to-real transfer for pick-and-place tasks with LLM-generated
  task decompositions.
